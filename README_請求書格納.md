## 請求書格納ツール（新規）
1. お客様を選ぶ（取引中・頻度低め・取引開始準備中）
2. 「何年何月分」を選ぶ（はじめは今月）
3. PDF / Excel / Word を置いて「格納庫に入れる」（複数まとめても可、1つ20MBまで）

→ Notion の顧客ページの子「<No>_<名>様請求書格納庫」に「2026年11月」トグルを作り、中にファイルを入れます。
   同じ月のトグルが既にあれば（「2026年_11月」「202611」の書き方でも）その中に追加します。
   格納庫ページが無いお客様は、最初の格納のときに自動で作ります。
   画面の下に、そのお客様の月ごとの中身（ファイル名）が出ます。

## 請求書発行ツール
- 請求日＝今日、振込期日＝翌月末 が入った状態で開きます。どちらも自由に変えられます。
- 請求日を変えると、振込期日をまだ触っていなければその翌月末に追従します。「今日・翌月末に戻す」ボタンあり。
- xlsx の B8（請求日）・B9（支払い期日）と、Notion格納庫への記録にそのまま使われます。
- 「Notionの顧客情報に記録」も、トグル名を格納ツールと同じ「2026年3月」にそろえ、同じ月のトグルがあればその中に追記します。
