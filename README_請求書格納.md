## 請求書発行ツール
- 一番上の「対象月」の下に「請求日・振込期日」。はじめは請求日＝今日、振込期日＝翌月末。どちらも自由に変えられます。
  請求日を変えると、振込期日をまだ触っていなければその翌月末に追従。「今日・翌月末に戻す」ボタンあり。
- 変えた日付は xlsx の請求日・支払い期日と、Notion格納庫への記録にそのまま使われます。
- 各お客様の行の「📁 格納」→ お客様と「何年何月分」（対象月が入った状態）を確認し、PDF/Excel/Word を置いて「格納庫に入れる」。
  Notion の顧客ページの子「<No>_<名>様請求書格納庫」に「2026年11月」トグルを作って中に入れます。同じ月のトグル（「2026年_11月」「202611」でも）があればその中に追加。
  格納庫ページが無いお客様は自動で作ります。画面の下にその人の月ごとの中身が出ます。
- 「Notionの顧客情報に記録」も同じ月トグルの中に追記するように統一（以前は「2026年_3月」で別トグルになっていた）。

## 顧客情報ページ
- 右上「＋ 顧客登録」で、お客様No.の自動採番（200/300/紹介/3000/通常/仮番/カスタム）・基本情報・チャンネル情報を入力して登録。登録後は後ろの一覧が自動で更新されます。
